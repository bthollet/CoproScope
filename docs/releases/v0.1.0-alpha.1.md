# CoproScope v0.1.0-alpha.1

> First public alpha for conseil syndical workflows.

## What is CoproScope?

CoproScope is an open source, local-first toolkit for conseils syndicaux.

It helps turn a scattered copropriete document folder into:

- clearer archives;
- structured registers;
- tracked requests to the syndic;
- AG preparation material;
- evidence-linked findings;
- reusable outputs that can be reviewed, shared or improved.

The alpha is deliberately not a turnkey consumer product yet. It is a first public base for testing, feedback and contribution.

## Who should test this alpha?

This release is suitable for:

- technical conseil syndical members;
- open source contributors;
- people comfortable with Python and command-line tools;
- syndics or property-management actors interested in more structured CS-syndic interactions;
- testers working only on the synthetic public corpus.

It is not yet suitable for:

- direct use by non-technical users without support;
- production processing of sensitive copropriete data without a local privacy review;
- legal, accounting or engineering decisions without professional verification.

## What is included?

### Core

- Public repository structure.
- Python package `coproscope`.
- CLI entry point: `coprocs`.
- Versioned configs, schemas, prompts and templates.
- Public synthetic copro instance.
- Minimal MCP server foundations.

### DocOps / DocuScope foundations

- Document inventory.
- Hash-oriented traceability.
- Text extraction foundations.
- Classification foundations.
- Completeness-oriented outputs.
- KPI-oriented outputs.

### SyndicOps foundations

- First structures for tracking requests to the syndic.
- First evidence-chain logic linking requests, documents, findings and diligences.

### AGOps / AGScope foundations

- First AG preparation signals.
- First support for identifying AG-related documents and preparation points.

### Public/private boundary

- Public sharing policy.
- Tooling around `share-audit` and `share-export`.
- Strong rule: real copropriete data must not enter the public repository.

## What is not included yet?

- A polished graphical interface.
- One-click installation.
- Mature RAG/chat experience over archives.
- Complete TravauxScope, PrestaScope or CoproLink modules.
- Full AG legal analysis.
- Production-grade anonymisation workflow.
- Complete automated test coverage.
- Legal, accounting or engineering advice.

## Safety rules for testers

Do not commit:

- real AG convocations or PVs;
- real contracts;
- real invoices;
- coproprietor names or lot numbers;
- bank data;
- debt recovery documents;
- litigation files;
- OCR outputs from a real copropriete;
- private reports generated locally.

Use the synthetic corpus for public tests and demonstrations.

## Suggested first tests

```bash
git clone https://github.com/bthollet/CoproScope.git
cd CoproScope/server
python -m pip install -e .
coprocs --help
```

Then test commands on the synthetic corpus only.
