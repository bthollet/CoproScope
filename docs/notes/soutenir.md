# Soutenir le projet

CoproScope est un logiciel libre, sous licence
[AGPL-3.0-only](../../LICENSE), développé à partir d'un besoin réel de conseil
syndical.

## Comment aider

- **Essayer la démo** et dire ce qui n'est pas clair : un retour de
  copropriétaire qui découvre le sujet vaut autant qu'un correctif.
- **Signaler un problème** dans les *issues* du dépôt, sans jamais y joindre de
  document réel ni de donnée personnelle.
- **Relire un contrôle juridique** : chaque source est déclarée avec sa version
  ([Le droit, jusque dans le code](ancrage-reglementaire.md)), et une relecture
  par une personne compétente est précieuse.
- **Contribuer du code** : voir [Développer](developper.md).
- **Associations, collectivités, partenaires** : un outil qui aide les conseils
  syndicaux à lire leur dossier est un outil de prévention. Pour en parler,
  ouvrir une *issue*.

Il n'y a pas, à ce jour, de programme de soutien financier.
