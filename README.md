# CoproScope

CoproScope is a local-first documentary and operational cockpit for conseil syndical workflows.

This repository separates:

- the reusable product code in [`server/`](./server),
- the implementation and roadmap documents in [`docs/`](./docs),
- a synthetic, non-sensitive validation instance in [`examples/synthetic_copro/`](./examples/synthetic_copro).

Real copropriete data, secrets, OCR outputs from private files, and instance-specific staging data do not belong in this product repository.

See the implementation contract in [`docs/implementation_plan.md`](./docs/implementation_plan.md).
See the public sharing policy for the GitHub target repository in [`docs/github_sharing.md`](./docs/github_sharing.md).
