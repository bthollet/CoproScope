Zone locale et chiffrement

hors cloud
Ce depot reste local Les fichiers sont copies dans le dossier local de l'instance. Cette page ne synchronise rien vers un service cloud.
Ce qui est prepare pour le coffre chiffre Les bruts, les cartes de correspondance, les secrets et les dossiers restreints restent dans les zones locales privees; ils sont exclus des exports servis par l'UI.
A verifier avant toute sync externe Utilisez les sorties biffage/confidentialite et les exports locaux uniquement apres arbitrage des pieces sensibles.

Parcours produit

piece -> action -> preuve
1. Depot Chaque fichier recoit une trace: nom stocke, taille, empreinte sha256 et manifeste de depot.
2. Traitement local Inventaire, extraction texte native, classement, screening confidentialite et file de biffage.
3. Rattachement Les documents alimentent l'atelier pieces, les points AG/incidents/comptes, les actions et les preuves attendues.
