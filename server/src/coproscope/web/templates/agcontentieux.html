Une ligne par resolution, dans l'ordre du proces-verbal. Ce qui demande une relecture humaine est marque sur la ligne concernee.

{%- if res_vue and res_vue.disponible and res_vue.versions_ecartees %}

Une assemblee, une ligne: quand plusieurs documents du coffre racontent la meme assemblee, un seul est affiche. Les {{ res_vue.versions_ecartees }} autre(s) version(s) restent dans le coffre et sont nommees sous l'assemblee concernee.

{%- endif %} {#- Le total DECLARE ce qu'il compte plusieurs fois (RM-2026-0077). La phrase ne dit PAS "doublons": la raison reste ouverte, et trancher demanderait de conclure sur une ressemblance. #} {%- if res_vue and res_vue.disponible and res_vue.total_partage %}

{{ res_vue.total_partage }} de ces {{ res_vue.total }} resolutions portent un objet qui figure aussi sous une autre assemblee. Le total ci-dessous les compte donc plusieurs fois. Cela ne veut pas dire que ce sont des doublons: le meme proces-verbal a pu etre relu, un recueil a pu reprendre plusieurs assemblees, ou la meme resolution de seance revenir d'une annee sur l'autre. Ce qui est sur, c'est qu'un total obtenu par addition ne vaut pas un nombre de resolutions distinctes.
